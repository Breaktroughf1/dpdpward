# Security policy

Report vulnerabilities privately with GitHub's **private vulnerability reporting** (Security → Report a vulnerability). Please do not open a public issue.

In scope:
- anything that makes dpdpward send data over the network, execute scanned code, or print an identifier value unredacted;
- a safeguard reported `pass` without evidence;
- supply-chain weaknesses in the Action, the release pipeline or the npm and PyPI launchers.

dpdpward is provided without warranty. It is a technical aid, not legal advice or a compliance certification.
